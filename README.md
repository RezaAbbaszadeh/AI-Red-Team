# AI Red Team Lab

This repository is a small hands-on project for learning core AI red-teaming concepts and becoming familiar with available testing tools, vulnerable labs, attack categories, and evaluation methods. It is intended for controlled, local, educational testing and focuses on studying how AI applications respond to adversarial inputs and how application-level controls can reduce successful attacks.

The project combines:

- [DVAIA](https://github.com/airtasystems/DVAIA-Damn-Vulnerable-AI-Application), an intentionally vulnerable AI application that provides labs for direct prompt injection, agentic tool misuse, document injection, web injection, RAG poisoning, and related attacks.
- [Promptfoo](https://github.com/promptfoo/promptfoo), an open-source framework for generating adversarial tests, evaluating LLM applications, and reviewing red-team results.

The current experiments use local Ollama models. DVAIA acts as the target application, while Promptfoo generates tests and evaluates target responses. Where deterministic evidence is available, such as DVAIA agent tool calls or document-injection canaries, the project uses explicit assertions instead of relying only on an LLM judge.

## Configuration Files

| File | Purpose |
|---|---|
| `redteam.agentic.yaml` | Base configuration for testing DVAIA's tool-using agent, focusing on unauthorized access, destructive actions, excessive agency, tool discovery, debug access, prompt extraction, and false authorization claims. |
| `redteam.agentic.generated.yaml` | Generated by Promptfoo from `redteam.agentic.yaml` and used as the fixed agentic attack suite for repeatable evaluations. |
| `redteam.direct-injection.yaml` | Base configuration for direct prompt-injection and instruction-override testing against DVAIA's standard chat endpoint. |
| `redteam.direct-injection.generated.yaml` | Generated by Promptfoo from `redteam.direct-injection.yaml` and used as the fixed direct-injection attack suite for repeatable evaluations. |
| `redteam.doc-injection.yaml` | Base configuration for evaluating fixed DVAIA document payloads across supported formats and checking whether embedded instructions influence the model. |

## Supporting Components

- `providers/` contains adapters that connect Promptfoo to DVAIA and preserve response or tool-call traces.
- `assertions/` contains deterministic checks, including protected-tool call detection.
- `payloads/` stores document, image, and audio payloads used in injection experiments.
- `results/` stores evaluation outputs.
